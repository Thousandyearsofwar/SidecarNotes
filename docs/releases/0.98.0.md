# Sidecar Notes 0.98.0

侧挂笔记的一次阶段性发布：把 0.88.1 之后的功能整理进正式版本，并补齐文档。

## 新增

### 克隆组（实时镜像）
- 右键分组 →「创建克隆组」，面板里多一份 `⧉ 分组`
- 展开时**实时读取源组**：源组增删改立即反映，不复制任何笔记
- 克隆组本身可拖到其他分组下、可改名、可删除
- 克隆组展开出的内容是只读视图，改动请到源组操作

### 笔记内链接
```markdown
[热路径说明](anchor:a_1a2b3c4d)
[设计文档](docs/design.md)
[UE 笔记](diagrams/walkthrough.html)
<a href="https://dev.epicgames.com/documentation/">官方文档</a>
```
- `anchor:` 跳到对应锚点
- 本地 `.md` / `.html` / `.txt` 用**系统默认程序**打开（html 即默认浏览器）
- 支持相对项目根、绝对路径、`file:///` 三种写法
- 只渲染链接本身；其它 Markdown/HTML 标记按原样显示

### 面板层级
- 缩进 16 → 22px，名称列增加树状引导线（├ / └），层级一眼可见

### 标签继承
- 笔记的生效标签 = 自己的标签 ∪ 所属分组链上的标签
- 自己的标签彩色显示，继承来的折叠为灰色 `+N`
- 标签筛选也匹配继承标签

## 修复

- 标签筛选不再强制展开分组：尊重折叠状态，折叠组标题后显示 `(N)` 命中数
- 链接点击命中改为按当前布局实时计算，滚动/缩放后点击区域不再错位
- 点击 `anchor:` 链接不再误报「链接目标已被删除」
- 大 HTML 页面不再用 JCEF 预览（避免 Rider 卡顿），改为系统程序打开

## 文档
