# Sidecar Notes 使用手册

本手册按实际使用顺序展开：建笔记 → 整理 → 打标签 → 链接 → 筛选 → 导入导出 → 排错。

---

## 1. 第一次使用

1. 打开任意 C# / C++ / 文本文件
2. 选中一段代码（**纯空白选区会被拒绝**，会提示「请先选中一段代码」）
3. `Ctrl+Alt+N`，弹出输入框
4. 输入笔记内容，`Ctrl+Enter` 保存（`Esc` 取消）

保存后：

- 代码块下方出现**摘要块**：标题 + 笔记正文，首行右侧是 `MM-dd HH:mm`
- 代码左侧出现**颜色带**和 gutter 图标
- 右侧工具窗口 **Sidecar Notes** 出现这条笔记

> 工具窗口没看到？`View → Tool Windows → Sidecar Notes`，
> 或点右侧边栏的 Sidecar Notes 图标。

---

## 2. 一条锚点写多条笔记

同一段代码可以反复追加笔记：

| 入口 | 行为 |
|---|---|
| 面板右键笔记 →「追加笔记」 | 给这个锚点再加一条 |
| 摘要块双击 | 编辑**最新**一条 |
| 面板里展开笔记（`▾`）再双击子笔记 | 编辑那一条 |

摘要块会按顺序列出所有笔记，每条首行右侧独立显示时间。
面板里笔记行前的 `▸/▾` 只在**有多条时**出现；点它只展开/折叠，不跳代码。

## 3. 分组

### 新建与整理

- 面板空白处右键 →「新建分组」
- 把笔记 / 分组**拖进**另一个分组（拖到行中间 1/2 区域）
- 拖到行**上 1/4** 插到它前面，**下 1/4** 插到它后面
- 拖到列表**底部空白**处 → 落到最后
- `F2` 重命名，`Delete` 删除（支持多选）

### 组的三个开关

每个分组行前面有三列勾选：**显示 / 锁定 / 简洁**。

- 勾掉「显示」：该组内的笔记不再在编辑器渲染
- 勾上「锁定」：该组内的笔记禁止编辑/删除
- 勾上「简洁」：每条笔记压成一行显示

组上的设置会被子组和笔记**继承**，行尾标 `（继承）`；
子项想覆盖继承值，直接改它自己的勾选即可。

### 克隆组

右键分组 →「创建克隆组」：面板里会出现第二个 `⧉ 分组`。

- 它是**只读镜像**：展开后显示源组的实时内容，源组增删改立即反映
- 克隆组本身可以拖到其他分组下、可以改名、可以删除
- 不能往克隆组里拖东西；也不能把克隆组拖进它自己的源组子树（会拒绝并提示）
- 删除源组时，指向它的克隆组会一并删除

## 4. 标签

### 建标签

1. 面板工具栏「标签库」
2. 新建标签 / 新建标签分组，拖拽排序与归组
3. 每个标签有颜色，双击或 `F2` 重命名

### 打标签

- 右键笔记 →「添加标签…」→ 按分组勾选（再点一次取消）
- 右键分组 →「添加标签…」→ 该组**所有笔记继承**

### 继承规则

```
笔记的生效标签 = 自己的标签 ∪ 所属分组链上的标签
```

- 自己的标签：彩色逐个显示
- 继承来的：折叠成灰色 `+N`（例如 `#热路径 #性能 +2`）
- 标签筛选包含继承标签：勾选父组标签，子组里的笔记也会被筛出
- 继承是只读的：想改继承标签，去对应分组上改
- 标签引用存的是 id，**重命名标签不会断开已挂载的标签**（列表里立刻显示新名字）

## 5. 笔记里的链接

支持的写法：

```markdown
[热路径说明](anchor:a_1a2b3c4d)
[设计文档](docs/design.md)
[UE 笔记](diagrams/walkthrough.html)
<a href="https://dev.epicgames.com/documentation/">官方文档</a>
```

| href 类型 | 点击行为 |
|---|---|
| `anchor:a_xxx` | 跳到对应锚点（打开文件 + 定位行 + 面板选中） |
| 本地 `.md` / `.html` / `.txt` | 用系统默认程序打开（html 即默认浏览器） |
| 绝对路径 `E:/.../x.html` | 同上 |
| `http(s)://` / `mailto:` | 用浏览器 / 邮件客户端打开 |
| 文件不存在 | 提示「引用文件不存在」 |

说明：

- **只有链接会被渲染**：显示成文字 + 蓝色下划线
- Markdown/HTML 的其它标记（`**粗**`、`#` 标题、`` `code` ``、`<b>`、`<span style>`）**按原样显示**
- 链接支持相对项目根、绝对路径、`file:///` 三种写法
- 面板右键笔记 →「打开引用的文件」可直接打开该笔记里的第一个引用

## 5.1 在笔记里写代码

用三个反引号把代码包起来，摘要块里就会按当前文件的语法着色：

````markdown
```cpp
State->Access = MakeValidAccess(AccessOld, AccessNew);
```
````

- 围栏行本身不显示
- 颜色取自 IDE 的编辑器配色方案（换主题自动跟随）
- 语言继承当前文件（`.cpp` 里就是 C++），暂不支持按围栏指定语言
- 代码里的链接不会被点击命中
## 6. 筛选

- 顶部**过滤框**：输入即匹配标题 / 正文 / 文件路径 / 标签（含继承标签）
- **标签筛选**：按标签库多选，命中任一即保留
- 筛选**不会改变你的折叠状态**；折叠的分组标题后会显示 `(N)` 表示子树里有多少命中
- 清空过滤框 / 清除标签筛选后恢复完整列表

---

## 7. 颜色、显示、锁定、简洁

| 操作 | 说明 |
|---|---|
| 右键 →「颜色 1–8」 | 覆盖该锚点/分组的颜色 |
| 组行三列勾选 | 显示 / 锁定 / 简洁，子项继承 |
| 分组颜色 | 子项未单独设色时继承 |

---

## 8. 撤销

面板内 `Ctrl+Z` 可撤销：

- 笔记的追加 / 编辑 / 删除
- 颜色覆盖
- 显示 / 锁定 / 简洁切换
- 重命名
- 标签增删
- 删除锚点 / 分组

**暂不支持**撤销：拖拽排序、标签库对话框里的改动。

---

## 9. 代码变了怎么办

锚点按**行号**记录，语义等同 IDE 书签：

| 情况 | 表现 |
|---|---|
| 会话内编辑 | `RangeMarker` 跟随，行号实时更新 |
| 重新打开项目 | 认存储行号；文件变短会夹到末尾 |
| 原文对不上 | 标 `⚠已变更`，笔记不动 |
| 想找回 | 右键「尝试重新定位」或「重新绑定到当前选区」 |

在锚点**上方**增删行，跨会话会整体偏移（书签也一样）。

---

## 10. 导入 / 导出

- 「更多 ▾」→「从 IDE 书签导入」：把 Rider 书签批量转成锚点
- 「更多 ▾」→「导出 Markdown / PR 评论」：把整个库导出成可粘贴的文本
- 导入策略可选「合并 / 仅导入 / 覆盖」

---

## 11. 数据与团队协作

```
<项目根>/.ridenotes/
  ├── _project.json                    # 分组树、标签库、面板状态
  └── <转义路径>.notes.json             # 每个源文件一个分片
```

- 提交到 git，团队成员共享同一批笔记
- 写入是临时文件 + 原子替换，不会写坏
- 换机器/换目录不影响（注意：绝对路径链接只在本机有效）
- 误删可 `git checkout` 找回

## 12. 排错

| 现象 | 处理 |
|---|---|
| 面板里看不到笔记 | 检查顶部过滤框 / 标签筛选；检查「显示」开关是否被关掉 |
| 编辑器里没有摘要块 | 设置里确认「在编辑器中显示摘要块」；折叠区间内的锚点不渲染 |
| 笔记标了 ⚠已变更 | 代码改动导致对不上，右键「尝试重新定位」或重新绑定 |
| 摘要块位置偏右 | 一般出现在从未显示过的区域，滚动到该区域后刷新（`Ctrl+Alt+R`） |
| 插件没生效 | 重启 Rider；看 `idea.log` 里的 `[RN]` 日志 |
| HTTP 接口连不上 | 设置里确认已启用，端口是否被占用（会自动顺延），令牌是否正确 |

日志：`%LOCALAPPDATA%\JetBrains\Rider2026.2\log\idea.log`，搜索 `[RN]`。
